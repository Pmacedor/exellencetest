# Excellence Odontologia Especializada

Landing page estática (HTML/CSS/JS puro) da clínica Excellence, Irecê - BA.

## Estrutura
- `index.html` - página completa
- `assets/` - fotos e logo otimizadas

## Publicar na Vercel
1. Suba este repositório no GitHub.
2. Na Vercel: Add New > Project > importe o repositório.
3. Framework Preset: **Other**. Deixe Build Command e Output Directory em branco.

Também funciona no GitHub Pages (Settings > Pages > branch `main`, pasta `/root`).
